Governed Claim Memory

ADR-0002 decides how a memory event earns standing: not by being written, but by passing through a governed write path and then being replayed into a deterministic StandingView.

ADR-0002 Status: Proposed Docs-only companion Ancestry, not machinery

The problem

Memory events must not become belief merely because they were written.

Magpie's L0 is the signed, append-only source of truth. That truth is about the log: what was written, by whom, when, in what order, and under what signature. It is not automatically truth about the world. ADR-0002 closes that gap with governed admission and replayable standing.

The decision

A memory event earns standing only through a governed write path and a deterministic projection over the append-only log. Standing is not an authoritative mutable field. It is derived, inspectable, and rebuildable.

Corrections are new events. Invalidations are new events. Ratifications are new events. The log is conserved; the projection derives the rest.

Deadbolt and Magpie

Deadbolt's role

Deadbolt proves or refuses occurrence. It can seal evidence bundles and emit SegmentAnchored events into Magpie after successful verification. It does not decide interpretation truth.

Magpie's role

Magpie preserves provenance, order, signatures, and inclusion. Its derived views decide what current standing follows from replaying governed claim, evidence, and justification events.

What the tamper field test proved

  • The tampered witness root was syntactically valid.
  • Reconcile re-verified before anchoring.
  • Reconcile refused the bundle.
  • The forged root was not appended.
  • Status reported debt without mutating the anchor log.
Therefore Deadbolt can protect occurrence anchoring; ADR-0002 governs what Magpie may believe about such evidence.

Evidence ceilings

A ceiling is a deterministic cap on what one evidence kind may establish alone. It is not numeric confidence.

Doctrine update: humans settle nothing epistemically. HumanRatification is governance/judgment evidence capped below Settled.

DeterministicVerificationMay reach Settled for exact predicates.

Edge vocabulary

Allowed

supports, derived_from, contradicts, supersedes, invalidates, ratifies

Rejected

related_to, similar_to, about, probably_true, associated_with

The vocabulary is intentionally restrictive to prevent relation slop.

v0 compatibility

  • ClaimAsserted: assertion with initial status, not current truth.
  • EvidenceRecorded: untyped evidence note, weak support ceilinged no higher than Supported.
  • ClaimStatusChanged: compatibility and emergency/manual ratification path until ratification-as-edge exists.
  • Note: ignored unless a later ADR says otherwise.
  • SegmentAnchored: occurrence evidence, not interpretation truth.

Rollout order

  1. Land the docs-only ADR-0002 package.
  2. Implement StandingView skeleton over existing v0 events only.
  3. Add enforcement tests against the v0-compatible StandingView.
  4. Only then implement future tags 6-8 with FORMAT, canonical encoding, golden vectors, verifier support, and explicit projection match arms.
  5. Add EpistemicGate / governed write admission.
  6. Only then expose governed write surfaces.

The projection earns the vocabulary; the vocabulary does not earn itself.

Ancestry, not machinery

Grounded argumentation, JTMS, screened belief revision, event sourcing, PROV-O, SLSA, in-toto, Dempster-Shafer discounting, legal corroboration, and interpretability work are useful ancestors. ADR-0002 does not import them as implementation semantics.

If Magpie later needs competing accepted standings, credulous acceptance, scope inheritance, or probabilistic fusion, ADR-0002 must be revisited before the fold expands.
