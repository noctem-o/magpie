# Deadbolt Witness/Evidence Machinery Survey

Scope: static repository survey for the Magpie-deadbolt seam. This is not a design recommendation and makes no code changes. In this report, `cog-kernel` refers to Deadbolt's diagnostic kernel crate; live mutation authorization is not described as routed through `cog-kernel` per `AGENTS.md`.

Size note: sizes below are approximate serialized JSON size classes from record shape and checked-in fixture presence. Exact bytes vary with string length, artifact vectors, stdout/stderr, notes, and issue vectors. Fixed root files are exact: 64 hex characters plus newline, 65 bytes.
